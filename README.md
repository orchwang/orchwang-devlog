## 🛠 Tech Stack

- **Framework**: Next.js 14.2.33, React 18.3.1, TypeScript 5.9.3
- **Content**: Contentlayer 0.3.4, MDX
- **Styling**: Tailwind CSS 3.4.18
- **Blog**: [Tailwind Nextjs Starter Blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) 기반

## 🚀 Quick Start

```bash
# Install dependencies
yarn install

# Run development server (port 3111)
yarn start

# Build for production
yarn build

# Run production server
yarn serve
```
